One pickup line a vending machine would use on a passing human. Written for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty.

## The line

> I must be a vending machine, because you press all my buttons and I still light up and give you everything for exact change.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because every part of it is vending-machine hardware played straight: pressed buttons, a lit-up display, exact change. The machine confesses it is hopeless — pushed around, lit up, handing over everything — and "for exact change" lands the joke, because a machine that gives everything away for exact change is a terrible machine and a devoted one. The flirtation is in the machine's own vocabulary, not borrowed from a human pickup line.
